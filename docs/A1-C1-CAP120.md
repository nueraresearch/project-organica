## Reading

A widening loop window removes K as the C1 blocker in the 16-tag blocks and in most of the 28-tag block. The remaining ceiling is the prediction path A, which is unchanged by the loop cap. This is a reason to test the prediction window next; it is not evidence that A can clear 60, and it is not an A1 run.

## What this does not claim

An availability-only counterfactual on 18 no-arm seeds. It measures the C1 ceiling, not a treatment effect, target viability or a successor. Widening the loop window is an engine-behaviour change, not an A1 cell; no target, freeze, grant or run follows.
